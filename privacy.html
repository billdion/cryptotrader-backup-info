Privacy policy

CryptoTrader Backup · Updated October 22, 2026

Purpose and access

This owner-operated personal utility uses Google Drive solely to upload, verify, download and restore encrypted backups. It requests the drive.file permission, which limits access to files created or explicitly opened with the application. It does not request access to Gmail, contacts or the owner's entire Drive.

Data and storage

Backup files contain application journal state, public configuration and recovery metadata. File contents and names are encrypted locally before upload. Trading private keys, alert credentials, OAuth credentials and encryption secrets are excluded from backup bundles.

Google receives encrypted files and the metadata needed to store and transfer them, including sizes and timestamps. OAuth tokens and recoverable encryption settings are held in a restricted local configuration file. Decrypted files exist locally during backup preparation, verification and restoration.

Use and sharing

The utility does not sell Google user data, use it for advertising, or use it to train AI models. It does not intentionally share backup files with other users or services. Google processes storage and authorization requests under its own policies.

Retention and control

The owner controls retention and can delete cloud copies through Google Drive and local copies through the host filesystem. There is no automatic deletion in the initial procedure. Revoking access through Google Account settings stops future authorized access; it does not delete existing copies.

This website

These static information pages contain no forms, analytics or application cookies. The hosting provider may process routine request information under its own policies. Backup files and credentials are not hosted here.

This tool is for its owner's use only. The OAuth consent screen identifies the configured support contact.
