CryptoTrader Backup

A personal utility for storing encrypted backup files in the owner's Google Drive and restoring them to an isolated local directory.

The utility uses rclone to encrypt file contents and names before upload. Google Drive access is limited to files created or explicitly opened with this application through the drive.file permission.

This is an owner-operated personal tool, not a public service. This website provides information only. It does not provide downloads, sign-in, trading, account registration or access to backups.
